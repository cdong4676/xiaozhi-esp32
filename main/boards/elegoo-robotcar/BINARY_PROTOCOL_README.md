# Elegoo机器人小车二进制通讯协议

## 协议概述

本文档描述了Elegoo机器人小车使用的二进制通讯协议，该协议用于高效传输视频流和控制命令。

## 协议格式

### 基本包结构

```
+--------+--------+----------+------+--------+
| Header | Header |  Length  | Type |  Data  |
|  0xFF  |  0x55  | (4 bytes)|(1 byte)| (N bytes) |
+--------+--------+----------+------+--------+
```

### 字段说明

| 字段 | 大小 | 类型 | 说明 |
|------|------|------|------|
| Header | 2字节 | 固定值 | 协议头：0xFF 0x55 |
| Length | 4字节 | uint32_t | 数据长度（包括Type字段，小端序） |
| Type | 1字节 | uint8_t | 数据类型 |
| Data | N字节 | 变长 | 实际数据内容 |

### 协议类型定义

| 类型值 | 名称 | 说明 |
|--------|------|------|
| 0x01 | VIDEO_FRAME | 视频帧数据 |
| 0x02 | COMMAND | 控制命令 |
| 0x03 | STATUS | 状态信息 |
| 0x04 | HEARTBEAT | 心跳包 |
| 0x05 | VOICE | 语音数据 |

## 视频帧协议 (Type = 0x01)

### 数据格式

```
+----------+----------+-------+--------+--------+----------+
| Frame ID |Timestamp | Width | Height | Format |JPEG Data |
|(4 bytes) |(4 bytes) |(2 bytes)|(2 bytes)|(1 byte)|(N bytes) |
+----------+----------+-------+--------+--------+----------+
```

### 字段说明

| 字段 | 大小 | 类型 | 说明 |
|------|------|------|------|
| Frame ID | 4字节 | uint32_t | 帧序号（小端序） |
| Timestamp | 4字节 | uint32_t | 时间戳（毫秒，小端序） |
| Width | 2字节 | uint16_t | 图像宽度（小端序） |
| Height | 2字节 | uint16_t | 图像高度（小端序） |
| Format | 1字节 | uint8_t | 图像格式（1=JPEG） |
| JPEG Data | N字节 | 二进制 | JPEG压缩的图像数据 |

### 示例

一个320x240的JPEG视频帧：
```
FF 55                    // 协议头
0D 04 00 00             // 长度：1037字节（包括Type）
01                      // 类型：视频帧
12 34 56 78             // 帧ID：0x78563412
AB CD EF 01             // 时间戳：0x01EFCDAB
40 01                   // 宽度：320
F0 00                   // 高度：240
01                      // 格式：JPEG
FF D8 FF E0 ...         // JPEG数据
```

## 协议优势

### 相比JSON协议的优势

1. **传输效率**：
   - 二进制格式，无需Base64编码
   - 减少约33%的数据传输量
   - 更快的解析速度

2. **内存使用**：
   - 直接传输二进制数据
   - 减少内存分配和拷贝
   - 更好的内存局部性

3. **实时性**：
   - 更低的延迟
   - 更稳定的帧率
   - 更好的网络利用率

4. **可扩展性**：
   - 明确的类型定义
   - 易于添加新的数据类型
   - 向后兼容性

## 性能参数

### 典型性能指标

- **视频分辨率**：320x240 (QVGA)
- **视频格式**：JPEG压缩
- **帧率**：10 FPS
- **典型帧大小**：8-15 KB
- **网络带宽**：约1 Mbps
- **延迟**：< 200ms
